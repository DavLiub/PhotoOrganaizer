# Settings Checklist

## Preconditions

- App is open.

## Checklist

- [ ] Tap the Settings icon in the top bar.
  Expected: Settings screen opens.

- [ ] Verify the Settings title.
  Expected: localized Settings title is visible.

- [ ] Verify the Language row.
  Expected: Language row is visible with a language icon.

- [ ] Verify the Google Drive row.
  Expected: Google Drive row is visible with a cloud icon.

- [ ] Verify the Backup profile row.
  Expected: Backup profile row is visible with a tuning icon.

- [ ] Tap each settings row.
  Expected: no destructive action happens; unfinished settings remain placeholders.

- [ ] Use the Android back action.
  Expected: app returns to the previous screen.

- [ ] Switch device locale to Russian and reopen Settings.
  Expected: Settings labels are shown in Russian where localization exists.
